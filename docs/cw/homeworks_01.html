1. Dekódování Morseova Kódu

Bodové ohodnocení 2 + 3 b
Použitý jazyk C
Vzorový program hw01_demorse-example.zip
Termín odevzdání 18.11.2026 23.59

Zadání

  • Navrhněte v jazyce C kód pro dekódování Morseova kódu. Uvažujte časovou jednotku $T_{\mathrm{dit}} = 120\,\mathrm{ms}$
  • Použijte vývojový kit AMP.
  • Vstup dekodéru je na pinu PB7 ($f_{measure}$)
  • Pro testování využijte kód ze cvičení a zapojte výstup Morseova kodéru (P3 nebo P6) na vstup dekodéru (P4), nebo propojte dvě desky
  • Navrhněte a implementujte postup příjmu symbolů:
    • kdy jsou symboly posílané typu ON-OFF (2 b),
    • kdy jsou symboly posílané jako tón (3 b),
    • nebo oba.
  • Implementujte dekodér.

Tip

  • Použijte časovač
  • Využijte FSM
